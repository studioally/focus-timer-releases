# Focus Timer

Odaklanma zamanlayıcısı — Windows ve Mac için.
*A focus timer for Windows and Mac.*

## ⬇️ İndir / Download

👉 **[En son sürümü indir / Download the latest version](https://github.com/studioally/focus-timer-releases/releases/latest)**

Sayfanın altındaki **Assets** bölümünden bilgisayarına uygun dosyayı seç:

| Bilgisayar | Dosya | Kurulum |
|---|---|---|
| **Windows** | `FocusTimer-Setup-x.y.z.exe` | Çift tıkla ve kur. Windows *"Bilgisayarınız korundu"* derse **Ek bilgi → Yine de çalıştır**. |
| **Windows (kurulumsuz)** | `FocusTimer-x.y.z-Windows-portable.zip` | Zip'i aç, `focus_app.exe` dosyasını çalıştır. |
| **Mac** | `FocusTimer-x.y.z-macOS.dmg` | Aç, Focus Timer'ı **Applications** klasörüne sürükle. İlk açılışta: Sistem Ayarları → Gizlilik ve Güvenlik → **Yine de Aç**. |

> "Source code" dosyalarına gerek yok; GitHub onları her sürüme kendiliğinden ekler.

## 💾 Verilerin güvende

- Uygulama her gün kendiliğinden yedek alır (Windows: `Belgeler\Focus Timer\Backups`).
- Uygulamayı kaldırıp yeniden kursan bile, açılışta eski verilerini geri yüklemeyi teklif eder.
- **Güncellemek için** yeni sürümü indirip üzerine kurman yeterli; verilerin olduğu gibi kalır.
